Exam-Day Strategy

  • 125 questions / 150 minutes → average about 72 seconds per question.
  • No negative marking → attempt every question.
  • First pass: answer easy questions quickly.
  • Second pass: return to calculation/conceptual questions.
  • Keep the last 10–15 minutes for unanswered questions and review.
  • Your strongest areas should be API, microservices, SQL and backend architecture. Use preparation time to close the Java/Spring gaps.
